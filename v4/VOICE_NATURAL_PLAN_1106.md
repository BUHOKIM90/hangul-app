# 목소리 대본 (11/06)

출고 금지: 복원본에 `audio/*.mp3`가 없으면 소리를 낼 수 없다. 진도 가져오기(JSON)는 음성 파일을 복원하지 않는다. `audio/have.js`와 `audio/*.mp3`가 1:1로 맞기 전에는 배포하지 않는다.

이 작업 트리에서는 mp3 982개가 `have.js`와 맞다. 녹음 도구(`v4/tools`)는 저장소에 없어 음성을 다시 만들지 않았다.

## 대본과 녹음이 다름

화면 말과 `audio/lines.js`의 아래 키는 유아에게 말하는 짧은 반말로 고쳤다. 재생되는 mp3는 이전 문장 그대로다. 아이가 듣는 소리와 글이 어긋난다. 이 키를 다시 녹음하기 전에는 음성 기준으로 출고하지 않는다.

| 키 | 새 대본 |
| --- | --- |
| ui4_today | 려원아, 오늘 뭐 하고 놀까? |
| ui4_bye | 오늘은 여기까지! 내일 또 놀자. |
| ui4_yest | 어제 본 친구, 기억나? |
| ui4_chant | 노래하자! 반짝이는 칸을 톡톡! |
| ui4_balloon | 풍선이 둥둥! 들은 글자를 톡! |
| ui4_sort | 같은 소리 친구끼리 모아 줄래? |
| ui4_block | 블록으로 글자 만들어 볼까? |
| ui4_box | 소리 하나, 상자 하나! |
| ui4_sticker | 빈칸에 뭐가 들어갈까? |

| ui_retry | 다시 한번 골라 볼까? |
| ui_merge | 조각을 붙이면 글자가 돼! |

화자는 하나(기존 몽글이 녹음)다. 친구 그림은 말투를 바꾸지 않는다. 한 문장에 할 일은 하나다. 아이가 카드를 누르면 `stopAudio()`로 안내를 끊고, 그다음 칭찬만 말한다. 칭찬은 `ui4_proc1`~`ui4_proc4`(끝까지 들었네, 획 순서, 혼자 읽었네, 블록을 골랐네)를 놀이 종류에 맞춰 쓴다. `천재네` 같은 말은 쓰지 않는다.

효과음은 `audio/sfx/*.wav`(짧은 합성음)다. 목소리 mp3를 새로 만들지 않았다. 목소리가 나오는 동안 효과음은 작게 줄어든다. 소리를 끄면 효과음도 없다. 동작 줄이기면 풍선·스티커 효과음은 톡으로 바뀐다.

저장소에 TTS 스크립트가 없어 1~55일 줄을 다시 녹음하지 못했다. 이 체크아웃의 mp3 982개는 `have.js`와 맞다. 복원본에 mp3가 0개면 출고하지 않는다.

## 대표님 듣기 확인 (A/B)

같은 문장을 이어폰으로, 그다음 폰 스피커 작은 소리로 들어 주세요. 각 줄은 새 대본(글)과 지금 녹음(mp3)이 다를 수 있습니다.

- A 글: 화면 말풍선. B 소리: 재생되는 mp3.
- 들을 키: `ui_hiname`, `ui4_today`, `ui4_chant`, `ui4_balloon`, `ui4_block`, `ui4_proc1`, `ui4_proc2`, `ui4_proc3`, `ui4_proc4`, `ui_retry`, `w_ai`, `w_eomma`, `w_mogi`.
- 체크: 한 문장에 할 일이 하나인가. 아이가 누르면 안내가 멈추는가. 칭찬이 과정을 말하는가. 첫소리(아, 엄, 모)가 뭉개지지 않는가. 로봇처럼 같은 높이로만 읽지 않는가.
- 어색하면 그 키만 다시 녹음. 효과음 wav로 목소리를 대체하지 않습니다.

어른 메뉴 아래에, `audio/ui_hiname.mp3`를 열지 못하면 출고 금지 문구가 붙는다.
