# 목소리 대본 (11/06)

출고 금지: 복원본에 `audio/*.mp3`가 없으면 소리를 낼 수 없다. 진도 가져오기(JSON)는 음성 파일을 복원하지 않는다. `audio/have.js`와 `audio/*.mp3`가 1:1로 맞기 전에는 배포하지 않는다.

이 작업 트리에서는 mp3 982개가 `have.js`와 맞다. 녹음 도구(`v4/tools`)는 저장소에 없어 음성을 다시 만들지 않았다.

## 대본과 녹음이 다름

화면 말과 `audio/lines.js`의 아래 키는 유아에게 말하는 짧은 반말로 고쳤다. 재생되는 mp3는 이전 문장 그대로다. 아이가 듣는 소리와 글이 어긋난다. 이 키를 다시 녹음하기 전에는 음성 기준으로 출고하지 않는다.

| 키 | 새 대본 |
| --- | --- |
| ui4_today | 려원아, 오늘 뭐 하고 놀까? |
| ui4_bye | 오늘은 여기까지! 내일 또 놀자. |
| ui4_yest | 어제 본 친구, 기억나? |
| ui4_chant | 노래하자! 반짝이는 칸을 톡톡! |
| ui4_balloon | 풍선이 둥둥! 들은 글자를 톡! |
| ui4_sort | 같은 소리 친구끼리 모아 줄래? |
| ui4_block | 블록으로 글자 만들어 볼까? |
