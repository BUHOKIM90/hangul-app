# 려원이 한글 놀이 v6.3

만 4세 아이가 놀면서 한글 읽기와 쓰기를 익히는 앱입니다. 소리 놀이 → 모음 → 자음+모음 블록 → 쌍자음 → 받침 → 이중모음 → 낱말 → 짧은 글 순서의 115단계(약 6개월)로 되어 있고, 한 번 열면 인터넷 없이도 동작합니다.

https://buhokim90.github.io/hangul-app/

- 기획서: `plan.md` · 검수표: `QA.md`
- 앱 코드: `index.html`, `sw.js`, `manifest.json`, `v6/`
- 소리: 기존 `audio/*.mp3`를 이름으로만 사용합니다. 녹음 앞뒤 무음은 `v6/js/trim.js`의 측정값으로 재생할 때 건너뜁니다.
- 내용(낱말·소리)을 바꾼 뒤에는 `node v6/tools/build.mjs .` 를 실행하세요. 쓰는 mp3가 모두 있는지 검사하고 `sw.js` 캐시 목록과 `trim.js`를 다시 만듭니다.
- 어른 메뉴: 오른쪽 위 자물쇠를 2초 누른 뒤 덧셈 문제를 풉니다. 이번 주 기록, 글자 지도(약한 글자), 오늘 같이 해 볼 것, 가족 목소리 녹음, 획순 확인·마이크 설정이 있습니다.
- 가족 목소리: 녹음 파일(mp3)이 없는 안내 말·글자는 가족이 녹음하면 그 목소리로, 녹음이 없으면 기기 목소리(한국어 TTS)로 나옵니다. 녹음은 그 기기(IndexedDB)에만 저장됩니다.
- 그림: `v6/img/e/`의 Fluent Emoji(MIT, `LICENSE.txt`)에 캐릭터와 같은 갈색 외곽선을 입혔습니다(`v6/tools/outline.mjs`, 빌드 때 자동).

## v6.3에서 바뀐 것
- 새 구역: 쌍둥이 숲(ㄲㄸㅃㅆㅉ, 7단계), 미끄럼 모음(ㅘㅝㅢㅟㅚ, 6단계), 이야기 하늘 10→12단계, 두·세 낱말 문구 18→44개. 기존 진도는 같은 단계로 자동으로 옮겨지고, 이미 지나간 자리에 새 단계가 생기면 그것부터 한 뒤 원래 자리로 돌아갑니다.
- 새 놀이 6가지: 글자 낚시, 글자 가게(이름표 끌어 건네기), 숨은 글자 찾기, 내가 읽어 볼게(녹음 → 내 목소리 → 정답 → 스스로 확인, 처음 보는 글자로 해독 확인), 쌍둥이 소리, 모음 미끄럼.
- 끌어 붙이기: 글자 블록·받침 블록·낱말 기차·글자 가게는 손가락으로 끌어서 빈칸에 넣습니다(눌러도 블록이 날아가 들어갑니다).
- 쓰기: 획 순서·방향이 분명히 틀린 획은 부드럽게 지우고 맞는 시작점을 반짝여 줍니다. 이름 혼자 쓰기는 '보고 쓰기 → 가리고 쓰기'.
- 모험 지도: 구역마다 풍경, 구역 경계 표지판, 길 끝에서 기다리는 친구. 구역에 들어갈 때 짧은 이야기, 끝나면 그 친구가 친구가 됩니다.
- 스티커 꾸미기: 주제별 그림판에 모은 스티커를 끌어 붙이고, 옮기고, 눌러서 크기를 바꿉니다.
- 화면 수정: 가로 아이패드에서 시작 버튼이 잘리던 문제, 큰 팝업이 화면 밖으로 나가던 문제, 글자 블록의 빈칸 표시.
