# 려원이 한글 놀이 v6.3

만 4세 아이가 놀면서 한글 읽기와 쓰기를 익히는 앱입니다. 소리 놀이 → 모음 → 자음+모음 블록 → 쌍자음 → 받침 → 이중모음 → 낱말 → 짧은 글 순서의 115단계(약 6개월)로 되어 있고, 한 번 열면 인터넷 없이도 동작합니다.

https://buhokim90.github.io/hangul-app/

- 기획서: `plan.md` · 검수표: `QA.md`
- 앱 코드: `index.html`, `sw.js`, `manifest.json`, `v6/`
- 소리: 기존 `audio/*.mp3`를 이름으로만 사용합니다. 녹음 앞뒤 무음은 `v6/js/trim.js`의 측정값으로 재생할 때 건너뜁니다.
- 내용(낱말·소리)을 바꾼 뒤에는 `node v6/tools/build.mjs .` 를 실행하세요. 쓰는 mp3가 모두 있는지 검사하고 `sw.js` 캐시 목록과 `trim.js`를 다시 만듭니다.
- 어른 메뉴: 오른쪽 위 자물쇠를 2초 누른 뒤 덧셈 문제를 풉니다. 이번 주 기록, 글자 지도(약한 글자), 오늘 같이 해 볼 것, 가족 목소리 녹음, 획순 확인·마이크 설정이 있습니다.
- 목소리: 모든 소리는 `audio/`의 녹음 파일만 씁니다(기기 합성 음성은 쓰지 않음). 새 놀이의 안내도 자막과 똑같은 말을 하는 기존 녹음으로 연결했습니다(`data.js` PROMPT_CLIP). 음성은 `v6/tools/voice/`의 문장 목록으로 GitHub Actions에서 ko-KR-SunHiNeural 한 목소리로 만들고, 한 번에 한 말·글자 수에 맞는 길이인지 자동 검사합니다(`report.json`). 가족 목소리 녹음(어른 메뉴)은 그 기기(IndexedDB)에만 저장되고, 가족 낱말·모험 이야기를 그 목소리로 바꿉니다.
- 글꼴: `fonts/Jua-Regular.woff2`는 Jua(OFL)에서 KS X 1001 한글 2,350자 + 앱에 쓰인 모든 글자로 다시 만들었습니다(이전 파일은 456자뿐이라 일부 글자가 다른 글꼴로 보였음).
- 가족 그림: 엄마·아빠·할머니·할아버지·아기·누나·려원·아이·어부는 `v6/img/w/`에 직접 그린 그림입니다.
- 검수: `python3 v6/tools/qa.py http://localhost:8770/ --sizes 1180x740,820x1100 --stages kinds` — 모든 단계 종류를 실제로 끝까지 플레이하고, 오류·멈춤·화면 밖 버튼·녹음 없는 소리를 보고합니다. 배포 전과 배포 후(배포된 커밋을 `git archive`로 꺼내 같은 검사) 두 번 돌립니다.
- 그림: `v6/img/e/`의 Fluent Emoji(MIT, `LICENSE.txt`)에 캐릭터와 같은 갈색 외곽선을 입혔습니다(`v6/tools/outline.mjs`, 빌드 때 자동).

## v6.3에서 바뀐 것
- 새 구역: 쌍둥이 숲(ㄲㄸㅃㅆㅉ, 7단계), 미끄럼 모음(ㅘㅝㅢㅟㅚ, 6단계), 이야기 하늘 10→12단계, 두·세 낱말 문구 18→44개. 기존 진도는 같은 단계로 자동으로 옮겨지고, 이미 지나간 자리에 새 단계가 생기면 그것부터 한 뒤 원래 자리로 돌아갑니다.
- 새 놀이 6가지: 글자 낚시, 글자 가게(이름표 끌어 건네기), 숨은 글자 찾기, 내가 읽어 볼게(녹음 → 내 목소리 → 정답 → 스스로 확인, 처음 보는 글자로 해독 확인), 쌍둥이 소리, 모음 미끄럼.
- 끌어 붙이기: 글자 블록·받침 블록·낱말 기차·글자 가게는 손가락으로 끌어서 빈칸에 넣습니다(눌러도 블록이 날아가 들어갑니다).
- 쓰기: 획 순서·방향이 분명히 틀린 획은 부드럽게 지우고 맞는 시작점을 반짝여 줍니다. 이름 혼자 쓰기는 '보고 쓰기 → 가리고 쓰기'.
- 모험 지도: 구역마다 풍경, 구역 경계 표지판, 길 끝에서 기다리는 친구. 구역에 들어갈 때 짧은 이야기, 끝나면 그 친구가 친구가 됩니다.
- 스티커 꾸미기: 주제별 그림판에 모은 스티커를 끌어 붙이고, 옮기고, 눌러서 크기를 바꿉니다.
- 화면 수정: 가로 아이패드에서 시작 버튼이 잘리던 문제, 큰 팝업이 화면 밖으로 나가던 문제, 글자 블록의 빈칸 표시.

## v6.3.1 (실사용 피드백 반영)
- 기계 음성(TTS) 완전 제거: 중국어처럼 들리던 소리, "그건 가야" 같은 어색한 말이 나오지 않습니다.
- 팝업(레벨업 등)이 사파리 툴바가 있는 짧은 화면에서도 버튼까지 보이도록 맞춤, 버튼이 하나인 팝업은 아무 곳이나 눌러도 넘어갑니다.
- 가족 그림 새로 그림, 글꼴 글자 수 보강.

## v6.3.2 음성 전면 재생성
- 이전 음성은 합성 엔진(Supertonic)이 짧은 글자에서 알아들을 수 없는 소리를 길게 덧붙인 파일이 많았습니다(예: '누' 8.4초, '사과' 6.4초, '고릴라' 12초).
- 모든 음성을 Microsoft 한국어 신경망 음성(ko-KR-SunHiNeural) 한 목소리로 다시 만들었습니다. 문장은 `v6/tools/voice/lines.json`(자막과 같은 말), 생성·검사는 `.github/workflows/voice.yml`이 합니다. 문장 목록을 바꿔 올리면 자동으로 다시 만들어집니다.
- 쌍자음·이중모음 글자(따·싸·짜·와·외·뭐 …)도 새로 만들어 쌍둥이 소리 비교가 완전해졌습니다.
